# About Spatial Movies

Spatial Movies is a new studio dedicated to creating spatial audiovisual media and traditional media about it.

We publish the site with [Eleventeen](https://eleventeen.blog), an [Eleventy](https://www.11ty.dev) blog starter whose name is an homage to the [Daisy Chainsaw album](https://en.wikipedia.org/wiki/Eleventeen_(album)). Browse the [spatialmovi.es source code](https://github.com/rdela/spatialmovi.es).
